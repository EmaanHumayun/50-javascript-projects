# Counter App

A modern interactive counter application built with HTML, CSS and JavaScript.

## Features

- Increase counter
- Decrease counter
- Reset counter
- Animated counter value
- Interactive status messages
- Responsive design
- Lucide icons

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Google Fonts

## JavaScript Concepts

- Variables
- Functions
- Increment operator
- Decrement operator
- DOM Manipulation
- Event Handling
- textContent
- setTimeout()
- External JavaScript library
