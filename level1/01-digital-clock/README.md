# Digital Clock

A simple digital clock built using HTML, CSS and JavaScript.

## Features

- Displays the current time
- Updates every second
- Uses JavaScript Date object
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts

- Functions
- Date Object
- DOM Manipulation
- getHours()
- getMinutes()
- getSeconds()
- String()
- padStart()
- Template Literals
- setInterval()
