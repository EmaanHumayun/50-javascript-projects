
# Project 07 — Atmos Weather Dashboard

Atmos is a modern, responsive weather dashboard built with HTML, CSS, JavaScript, and popular front-end libraries.

## Features

- Search weather by city
- Current temperature and weather conditions
- Feels-like temperature, humidity, and wind speed
- UV index and precipitation probability
- Interactive 12-hour temperature chart
- Five-day weather forecast
- Sunrise, sunset, and daylight duration
- Browser-based current location
- Popular city shortcuts
- Responsive desktop and mobile design
- Loading indicators and error handling

## Technologies & Libraries

- HTML5
- CSS3
- JavaScript ES6+
- Tailwind CSS CDN
- Lucide Icons
- Chart.js
- Open-Meteo Geocoding API
- Open-Meteo Forecast API

## How to Run

1. Open this folder in Visual Studio Code.
2. Install the Live Server extension if you don't already have it.
3. Open `index.html` with Live Server.
4. Search for a city or use the location button.
5. Allow location access if you want to use your current coordinates.

An internet connection is required for the libraries and weather data.
